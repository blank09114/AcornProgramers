# 🧠 에이콘 프로그래머스 (Acorn Programers)

문제 풀이, 랭킹, 포인트 상점, 커뮤니티 기능이 결합된 개발자 학습용 웹 애플리케이션입니다.

---

## 📌 프로젝트 개요
- **개발 형태**: Java + JSP 기반 웹 애플리케이션  
- **개발 인원**: 5인( 김민환, 김유민, 박예린, 이정호, 정연수)  
- **핵심 목표**  
  - 문제 풀이 → 포인트 → 상품 구매 선순환 구조  
  - 커뮤니티 기능을 포함한 사용자 중심 웹 플랫폼 구현  
  - JSP와 JDBC를 활용한 데이터 흐름 이해 및 실습  

---

## 🛠️ 기술 스택
| 분야 | 사용 기술 |
|------|-----------|
| Front-end | HTML, CSS, JavaScript, JSP |
| Back-end | Java(Servlet), JDBC |
| Database | Oracle 12c |
| Tools | Eclipse, VS Code, Git |

---

## 🔍 주요 기능
| 기능 구분 | 설명 |
|-----------|-------|
| 문제 풀이 | 문제 목록 확인 및 풀이 → 정답 여부에 따라 점수 지급 |
| 랭킹 시스템 | 사용자 포인트 누적 기반 순위 출력 |
| 포인트 상점 | 포인트로 상품 교환 가능 (DB 연동) |
| 커뮤니티 게시판 | 게시글 CRUD, 댓글 작성/삭제 |
| 회원 시스템 | 회원가입, 로그인, 관리자 페이지 분리 |
| DB 연동 | JDBC 기반 DB 연결 및 쿼리 실행 |

## ⚙️ 기술적 구현
- **MVC 구조 일부 적용**: Servlet → DAO/DTO → JSP  
- **DAO 기반 SQL 실행**: `PreparedStatement`로 CRUD 처리, DTO 객체로 데이터 전달  
- **UI 처리**: JSP 내 scriptlet 기반 로직, JavaScript로 유효성 검사  
- **기능 흐름 연계**: 문제 풀이 → 포인트 누적 → 상점 교환 → 랭킹 시스템까지 단일 사이클 완성
