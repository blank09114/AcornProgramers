# 에이콘 프로그래머스(Acorn Programers)

문제 풀이, 랭킹, 커뮤니티, 포인트 상점 기능을 결합한 학습용 웹 애플리케이션입니다.

---
## 프로젝트 개요

코딩 문제 풀이와 랭킹 시스템, 커뮤니티 기능을 제공하는 학습용 웹 애플리케이션입니다. 사용자가 문제를 풀고 점수를 획득하면 랭킹에 반영되며, 획득한 포인트를 통해 상품을 구매할 수 있도록 구성했습니다.
저는 ERD 및 클래스 다이어그램 설계, 메인 페이지 및 커뮤니티 기능 구현, 발표 자료 제작을 담당했습니다.

- 개발 형태: JSP/Servlet 기반 웹 애플리케이션
- 개발 인원: 5인

## 구조 및 설계
### 전체 구조

Servlet 기반 MVC 구조를 사용해 요청 처리, 비즈니스 로직, 데이터 접근, 화면 렌더링을 분리했습니다. 사용자 요청은 Servlet에서 처리하고, DAO를 통해 Oracle DB에 접근한 뒤 JSP를 통해 화면을 렌더링하는 방식으로 구성했습니다.

### ERD 및 클래스 설계

ERD를 통해 사용자, 게시글, 댓글, 문제, 랭킹, 상품 데이터를 설계하고 관계를 정의했습니다. 또한 클래스 다이어그램을 작성해 DAO, DTO, Servlet 구조를 정리했으며, 설계 단계에서부터 DB 구조와 클래스 구조가 연결되도록 문서화했습니다.

### 계층 분리

DAO, DTO 구조를 활용해 데이터 접근과 데이터 전달을 분리했습니다.
- DAO: SQL 실행 및 DB 접근
- DTO: 데이터 전달 객체
- Servlet: 요청 처리 및 흐름 제어
- JSP: View 렌더링
이를 통해 기능별 역할을 구분하고 코드 재사용성을 높이고자 했습니다.

## 주요 기능

- 회원: 회원가입, 로그인, 로그아웃
- 문제 풀이: 문제 목록 조회 및 정답 처리
- 랭킹: 사용자 점수 기반 순위 출력
- 포인트 상점: 포인트 기반 상품 구매
- 커뮤니티: 게시글 및 댓글 CRUD, 좋아요, 검색 기능
- 메인 페이지: 문제 풀이, 랭킹, 커뮤니티 이동 및 사용자 상태 기반 UI 제공

## 구현
### 메인 페이지

사용자가 가장 먼저 접근하는 진입 화면으로, 문제 풀이·랭킹·커뮤니티 페이지로 이동할 수 있도록 구성했습니다. 로그인 여부에 따라 메뉴와 사용자 정보가 다르게 표시되도록 처리했으며, 랭킹과 인기 게시글을 메인 화면에서 함께 확인할 수 있도록 구성했습니다.

### 커뮤니티 기능

게시글 작성, 수정, 삭제 및 상세 조회 기능을 구현했습니다. 검색 기능과 좋아요, 댓글 작성 및 삭제 기능을 추가해 사용자 간 상호작용이 가능하도록 구성했으며, 게시글 작성 시 입력값 유효성 검사를 적용해 사용자 경험을 개선했습니다. 또한 댓글 및 좋아요 기능은 비동기 요청 기반으로 처리해 페이지 전체를 새로고침하지 않고 상태를 갱신할 수 있도록 구현했습니다.

### 문제 풀이 및 랭킹 시스템

사용자가 문제를 풀고 점수를 획득하면 랭킹에 반영되는 구조를 구현했습니다. 퀴즈 목록 및 상세 페이지를 구성하고, 정답 여부에 따라 사용자 점수를 갱신하도록 처리했습니다. 랭킹 페이지에서는 사용자 점수를 기준으로 순위를 계산하고 페이지네이션을 적용해 출력했습니다.

### 포인트 상점 및 주문 기능

사용자가 획득한 포인트를 사용해 상품을 구매할 수 있도록 구성했습니다. 장바구니, 배송지 입력, 주문 완료 흐름을 구현했으며, 주문 시 사용자 포인트와 상품 정보를 기반으로 주문 데이터를 처리하도록 구성했습니다.

### 회원 및 인증 처리

회원가입 및 로그인 기능을 구현하고, 세션을 통해 로그인 상태를 관리했습니다. 또한 Google 및 Kakao OAuth 로그인을 구현해 외부 계정을 통한 로그인도 지원하도록 구성했습니다. 회원 탈퇴 시에는 사용자의 게시글 및 댓글 데이터를 함께 삭제하도록 처리했으며, 트랜잭션을 활용해 중간 오류 발생 시 롤백되도록 구성했습니다.

## 기술적 고민 및 개선점
### 보안 처리

회원 비밀번호를 평문으로 저장 및 검증하는 구조였기 때문에 실제 서비스 수준의 보안에는 한계가 있었습니다. 향후에는 BCrypt와 같은 해시 기반 암호화를 적용하고, 인증 및 보안 구조를 개선할 필요가 있다고 판단했습니다.

### 구조 확장성

Servlet과 JSP 기반으로 기능을 구현하면서 기능이 증가할수록 요청 흐름과 화면 구조 관리가 복잡해지는 문제를 경험했습니다.이후에는 Spring MVC와 같은 프레임워크를 활용해 구조를 더 체계적으로 관리할 필요가 있다고 느꼈습니다.

### 기능 완성도

짧은 개발 기간으로 인해 일부 자잘한 버그와 세부 기능 부족 문제가 있었습니다. 텍스트 에디터, 파일 업로드, 학습 보조 기능 등은 구현하지 못해 아쉬움이 남았으며, 이후에는 CKEditor, Quill과 같은 에디터 라이브러리 및 AI 기반 기능 도입을 고려할 수 있다고 생각했습니다.

---
### 사용자 경험

기능 구현에 집중하면서 사용자 친화적인 학습 보조 기능은 충분히 구현하지 못했습니다. 추후에는 힌트 시스템, 추천 문제, AI 챗봇 등 사용자 경험을 강화할 수 있는 기능을 추가할 수 있다고 생각했습니다.
