# 🧠 에이콘 프로그래머스 Acorn Programers

> 문제 풀이, 랭킹, 포인트 상점, 커뮤니티 기능이 결합된 웹 플랫폼.  
> **JSP, Java, Oracle** 기반으로 구현한 개발자 학습용 웹 애플리케이션입니다.

---

## 📌 프로젝트 개요

- **개발 형태**: Java + JSP 기반 웹 애플리케이션
- **개발 인원**: 5인 (박예린, 김민환, 김유민, 이정호, 정연수)
- **핵심 목표**:
  - 문제 풀이 → 포인트 → 상품 구매의 선순환 구조
  - 커뮤니티 기능을 포함한 사용자 중심 웹 플랫폼 구현
  - JSP와 JDBC를 활용한 데이터 흐름 이해 및 실습

---

## 🛠️ 기술 스택

| 분야        | 사용 기술 |
|-------------|-----------|
| Front-end   | JSP, HTML, CSS, JavaScript |
| Back-end    | Java (Servlet), JDBC |
| Database    | Oracle 12c |
| Tools       | Eclipse, VS Code, Git |
| 배포 방식   | 로컬 Tomcat 실행 또는 코드 공유용 |

---

## 🧩 주요 기능

| 기능 구분        | 설명 |
|------------------|------|
| 문제 풀이        | 문제 목록 확인 및 풀이 → 정답 여부에 따라 점수 지급 |
| 랭킹 시스템      | 사용자 포인트 누적 기반 순위 출력 |
| 포인트 상점      | 포인트로 상품 교환 가능 (DB 연동) |
| 커뮤니티 게시판  | 게시글 작성, 수정, 삭제 / 댓글 기능 포함 |
| 회원 시스템      | 회원가입, 로그인, 관리자 페이지 분리 |
| DB 연동          | Oracle DB 기반 JDBC 직접 연결 및 쿼리 실행 |

## 🗃️ DB 테이블

> 전체 ERD 및 테이블 정의는 결과보고서 참조

- `user_tbl`: 사용자 정보
- `question_tbl`: 문제 정보
- `solve_tbl`: 문제 풀이 기록
- `point_tbl`: 포인트 누적 데이터
- `product_tbl`: 포인트 교환 상품 정보
- `community_tbl`: 게시글
- `comment_tbl`: 댓글

## 🎯 프로젝트 특징

- 💾 **JDBC 직접 사용**: 프레임워크 없이 Java로 직접 DB 연동
- 📑 **JSP 중심 UI**: JSTL 없이 scriptlet 기반 구조
- 🧩 **문제 → 포인트 → 상점 흐름**: 학습형 플랫폼 구조
- 🧵 **전체 기능 흐름 완성**: 문제풀이, 상점, 커뮤니티, 랭킹 연계
